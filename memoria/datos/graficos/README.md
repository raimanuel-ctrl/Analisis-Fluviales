# Entradas de los gráficos del informe

Estos archivos completan los datos de precisión completa de la carpeta superior. Conservan las referencias manuales, los ensayos y los diagnósticos que aparecen en los gráficos del informe, sin convertirlos en nuevas selecciones adoptadas.

| Archivo | Contenido |
| --- | --- |
| `inventario_figuras.json` | Los 56 pies de figura, clasificación y dependencia externa. |
| `kp_referencias_manuales.csv` | Posición manual anterior a la revisión de cada KP. |
| `latitudes_kp.csv` | Latitudes derivadas de las posiciones de los KP. |
| `latitudes_calibracion.csv` | Referencias latitudinales de los casos de K. |
| `regresiones_completo_3km.csv` | Coeficientes, intervalos, cruces y validación local de la comparación. |
| `sensibilidad_tiempos_altura.csv` | Tiempos con altura DEM y altura publicada. |
| `k_uniformes.csv` | Calibraciones uniformes de referencia. |
| `norte_donantes.csv` | Ensayo de tres donantes y posiciones alternativas de R02–R04. |
| `R02_completo.csv`–`R04_completo.csv` | Geometrías completas del ensayo norte. |
| `R##_perfil_costa.csv` | Cuatro perfiles costeros de la figura 8. |
| `cruces_perfil_fallas.csv` | Distancias de intersección sobre el perfil; entrada de la figura 26. |
| `concavidad_exploratoria.csv` | Diagnóstico histórico R²–θ de los perfiles completos. |
| `JM2015_OD_alicuotas.csv` | Doce registros de OD/alícuotas de la tabla 1 publicada, con la selección de la memoria. |

El archivo de concavidad describe la exploración guardada previa a algunas geometrías finales. Los archivos del ensayo norte conservan el alcance de ese ensayo. Los datos de las comparaciones externas de las figuras 2, 16 y 29 se suministran localmente, según [GRAFICOS_DEL_INFORME.md](../../docs/GRAFICOS_DEL_INFORME.md).

Las coordenadas de perfiles y KP son derivados propios. Las ubicaciones del catálogo espacial original de terrazas, los valores no publicados de colaboradores y el libro privado Ages_Final quedan fuera de esta carpeta.
