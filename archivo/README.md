# Archivo de investigación anterior

Esta carpeta conserva la publicación y los antecedentes de octubre de 2026. La versión vigente se encuentra en [memoria](../memoria/README.md).

| Carpeta o archivo | Contenido |
| --- | --- |
| `notebooks/actual_20261022` | Siete notebooks, módulos y síntesis de octubre. |
| `notebooks/` | Flujo anterior de topografía, perfiles, K, terrazas y fallas. |
| `ai_context/` | Exportaciones de lectura del código histórico. |
| `docs/` | Revisiones y comprobaciones de las publicaciones anteriores. |
| `README_raiz_20261022.md` | Documentación de entrada original. |
| `AI_CONTEXT_20261022.md` | Contexto técnico de esa versión. |

Los archivos se conservan como antecedentes. Sus rutas relativas fueron escritas para la organización anterior. Para recuperar el árbol ejecutable original, consultar el commit [fcef1cf79e760a3596ff052abd386e38a36cc725](https://github.com/raimanuel-ctrl/Analisis-Fluviales/tree/fcef1cf79e760a3596ff052abd386e38a36cc725). Los archivos históricos pueden describir geometrías y orígenes temporales que luego cambiaron, especialmente en Rahue y Curanilahue. Sus resultados no deben mezclarse con las tablas finales de noviembre.

La reorganización conserva el contenido de los archivos metodológicos. No reejecuta la extracción D8 original ni promueve sus ensayos a resultados finales.
